### About Me

I'm a 3rd-year engineering student who learns by building — currently deep-diving into backend engineering and site reliability, with an eye on distributed systems. I spend my time debugging real issues in large open-source codebases, writing REST APIs from scratch, and picking apart production postmortems to understand *why* things break.

- ✅ Shipped my first merged PR to **`kubernetes/community`** (#9083 — added `@release-comms` usergroup to sig-release)
- 🌱 Learning REST APIs from the ground up — hands-on with Postman, and building a notes API in **Spring Boot**
- 📖 Running my own "postmortems" of Kubernetes architecture — RCA technique + failure analysis, as prep for SRE work
- 🎯 Working toward **LFX Mentorship** and **GSoC 2027**
- 🏆 Competing in **Smart India Hackathon (SIH) 2026**
- 💬 Ask me about Kubernetes internals, REST API design, or how to read a CI flake like a detective novel
